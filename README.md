## Technology Stack

| Component | Technology |
|-----------|------------|
| Backend | NestJS (Node.js Framework) |
| API | REST API |
| Frontend | Next.js / React |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Database | PostgreSQL / MySQL |
| ORM | Prisma ORM |
| Containerization | Docker / Docker Compose |
